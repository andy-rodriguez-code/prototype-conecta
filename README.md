# Conecta Créditos · Prototipo web

Prototipo de la web de Conecta Créditos (HTML, CSS y JavaScript, sin dependencias).

**Ver en línea:** https://andy-rodriguez-code.github.io/prototype-conecta/

## Estructura
- `index.html` — contenido de la página
- `css/styles.css` — estilos
- `js/main.js` — menú, animaciones, simulador de cuota, formulario y WhatsApp

El número de WhatsApp se cambia en `js/main.js` (`CONFIG.whatsapp`).
